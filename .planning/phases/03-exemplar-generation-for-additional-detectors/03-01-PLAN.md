  <action>
Create code/source-code/generate_prompt_text.py with the following behavior:

CLI interface:
  --data_root       Path to FSC147 root dir, default: "./data/FSC147"
  --split           Which split to process: "val" | "train" | "test", default: "val"
  --output_file     Output JSON path, default: "./data/FSC147/annotation_FSC147_pos_prompt_text.json"
  --delay           Seconds to sleep between Gemini API calls (default: 0.5, for rate limiting)

Logic:
1. Read GEMINI_API_KEY from os.environ — raise RuntimeError if missing with message:
   "GEMINI_API_KEY is not set. Export it in your shell before running."
2. Load split list from data_root/Train_Test_Val_FSC_147.json → target_images = set(data[split])
3. Load class map from data_root/ImageClasses_FSC147.txt → dict {img_name: class_name}
4. Resume support: if output_file already exists, load it → result_map = existing JSON.
   Skip any img_name already present in result_map. Print: "Resuming: {N} images already done."
5. For each img_name in sorted(target_images):
   a. If already in result_map, skip
   b. img_path = data_root/images_384_VarV2/img_name
   c. image = Image.open(img_path).convert("RGB")
   d. class_name = class_map.get(img_name, "object")
   e. enhanced = enhance_prompt_with_gemini(image, class_name)
      (from prompt_enhancer.py — handles Gemini API errors + retries internally)
   f. result_map[img_name] = {"positive_descriptions": [enhanced]}
   g. print(f"[{i}/{total}] {img_name} ({class_name}) → {enhanced[:60]}")
   h. time.sleep(args.delay)
   i. Every 100 images: save result_map to output_file (checkpoint write)
6. Final save: write result_map to output_file as JSON with indent=2
7. Print: f"Done. {len(result_map)} entries saved to {output_file}"

Security: GEMINI_API_KEY MUST only be read from environment (os.environ.get("GEMINI_API_KEY")).
Never log the key value. The existing prompt_enhancer.py handles this correctly — import it
directly (do not duplicate the Gemini client initialization).
  </action>
