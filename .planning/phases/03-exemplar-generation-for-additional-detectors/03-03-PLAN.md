<objective>
Run generate_prompt_text.py (created in Plan 01) locally to produce
annotation_FSC147_pos_prompt_text.json for the full val split (1286 images).

This file is the prerequisite for Plan 04 (the --prompt runs for DET-04).
It maps each val-split image to a Gemini-generated visual description:
  {"1050.jpg": {"positive_descriptions": ["single bread roll . round . golden brown ."]}, ...}

Runs locally (not on GPU server) because it only calls the Gemini API — no GPU needed.
Gemini API key must be set in shell: export GEMINI_API_KEY=<your key>
Estimated time: 1286 images × ~1–2 API calls each ≈ 30–90 minutes
(rate-limited to 0.5s delay between calls by default; adjustable with --delay)

Purpose: DET-04 requires Rich Prompt exemplar generation, which requires this file first.
</objective>
