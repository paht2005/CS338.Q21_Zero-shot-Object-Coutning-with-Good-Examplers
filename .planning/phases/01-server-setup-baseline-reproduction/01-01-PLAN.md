Create `scripts/server_setup.sh` for execution on the remote server (NOT locally). This script is meant to be run after SSH-ing into counting@192.168.6.200 from the repo root.

The script must:
1. Accept optional env name arg (default: `vacount`)
2. Create conda env: `conda create -n vacount python=3.10 -y`
   (Use 3.10, not 3.12, for better CUDA 11.x/12.x compat with torch+GroundingDINO)
3. Activate: `eval "$(conda shell.bash hook)" && conda activate vacount`
4. Install GroundingDINO editable: `cd code/source-code/GroundingDINO && pip install -e . && cd ../../..`
5. Install main deps: `pip install -r code/source-code/requirements.txt`
6. Install CLIP: `pip install git+https://github.com/openai/CLIP.git`
7. Verify data paths exist on NAS:
   ```bash
   for path in \
     /mnt/mmlab2024nas/counting \
     /mnt/mmlab2024nas/counting/fsc147/images_384_VarV2 \
     /mnt/mmlab2024nas/counting/fsc147/gt_density_map_adaptive_384_VarV2 \
     /mnt/mmlab2024nas/counting/fsc147/Train_Test_Val_FSC_147.json; do
     if [ ! -e "$path" ]; then echo "MISSING: $path"; fi
   done
   ```
8. List checkpoint files found under /mnt/mmlab2024nas/counting/ matching *.pth
9. Print final status: "Setup complete. Run: bash scripts/verify_env.sh"

Use `set -euo pipefail`. Add comments for each section.
