Create `scripts/run_evaluation_val.sh` — a modified version of `scripts/run_evaluation.sh` that:

1. Accepts `DATA_BASE` env var (default: `/mnt/mmlab2024nas/counting`) for NAS prefix
2. Derives paths:
   ```bash
   DATA_BASE="${DATA_BASE:-/mnt/mmlab2024nas/counting}"
   FSC_DIR="${DATA_BASE}/fsc147"
   CKPT_DIR="${DATA_BASE}/checkpoints"
   SRC="code/source-code"
   ```
3. Runs 4 configs with `--split val`. For each config, if the annotation file does NOT exist at the expected path, print a warning and skip (don't fail hard) so partial runs produce partial results:
   ```bash
   # Config 1: VA-Count Baseline
   ANNO="${FSC_DIR}/annotation_FSC147_384.json"
   CKPT="${CKPT_DIR}/checkpoint_FSC.pth"
   # Also check local data/ fallback: code/source-code/data/checkpoint_FSC.pth
   # Use local if NAS path missing

   # Config 2: GroundingDINO + Rich Prompt
   ANNO="${FSC_DIR}/annotation_FSC147_pos.json"
   CKPT="${CKPT_DIR}/checkpoint__finetuning_dino_prompt.pth"

   # Config 3: YOLO-World (no Rich Prompt)
   ANNO="${FSC_DIR}/annotation_FSC147_pos_yolo_noprompt.json"
   CKPT="${CKPT_DIR}/checkpoint__finetuning_yolo_noprompt.pth"

   # Config 4: YOLO-World + Rich Prompt
   ANNO="${FSC_DIR}/annotation_FSC147_pos_yolo_prompt.json"
   CKPT="${CKPT_DIR}/checkpoint__finetuning_yolo.pth"
   ```
   Also check local fallback paths (`code/source-code/data/`) for both anno files and checkpoints.

4. For each config, the python call is:
   ```bash
   cd "${SRC}" && python FSC_test.py \
     --data_split_file "${FSC_DIR}/Train_Test_Val_FSC_147.json" \
     --im_dir "${FSC_DIR}/images_384_VarV2" \
     --gt_dir "${FSC_DIR}/gt_density_map_adaptive_384_VarV2" \
     --anno_file "${ANNO}" \
     --output_dir "output/val_${CONFIG_NAME}" \
     --resume "${CKPT}" \
     --split val \
     --external 2>&1 | tee "../../experiments/server-val-baseline/${CONFIG_NAME}.log"
   cd ../..
   ```
   Replace `${CONFIG_NAME}` with: `baseline`, `dino_rich`, `yolo_norich`, `yolo_rich`

5. After all configs, print a summary section:
   ```
   === RESULTS SUMMARY ===
   Config | Output dir
   ...
   Run: grep -r "MAE\|RMSE" experiments/server-val-baseline/*.log
   ```

Use `set -euo pipefail` at the top. Create the output dir `experiments/server-val-baseline/` if it doesn't exist.
